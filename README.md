# Loan Default Analysis Dashboard

An interactive Data Analytics and Business Intelligence project built using Excel, MySQL, SQL, Power BI, and DAX to analyze borrower behavior and identify factors associated with loan defaults.

## Project Overview

This project analyzes 20,000+ loan records to uncover patterns in borrower demographics, credit behavior, income levels, employment type, education, and loan purpose. The objective is to help financial institutions make data-driven lending decisions through interactive dashboards and analytical insights.

## Business Problem

What factors are associated with loan defaults, and how can a bank use these insights to improve lending decisions?

The dashboard was designed to answer questions such as:
- Which loan purposes have the highest default rate?
- How do credit scores differ between defaulters and non-defaulters?
- Does income influence repayment behavior?
- Which customer segments appear riskier?

## Key Insights

- Business loans show the highest observed default rate.
- Borrowers with lower credit scores exhibit higher default risk.
- Income levels influence repayment behavior.
- Employment type is associated with differences in default probability.
- Loan purpose contributes to variations in default rates.

## Business Recommendations

- Apply stricter credit checks for low credit score applicants.
- Review lending policies for higher-risk loan purposes.
- Include employment type in credit risk assessment.
- Combine income and credit score for better borrower evaluation.
